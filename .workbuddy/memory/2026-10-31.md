## 硬事实（用户纠正，2026-10-31）

**SKU ID 平台唯一，一个 SKU 只属于一条链接。** 把同一规格加到另一条链接上，平台会生成**新的** SKU ID。
所以「SKU ID → 商品ID」是一劳永逸的对应，不存在"改挂/rebind"。
以后再拿"改挂"当理由就是错的（v0.23.2 / v0.23.5 的 changelog 就是错的，v0.23.6 已更正）。
按区间挑 SKU 表的真实理由只有两条：①按区间的表含本期新上架 SKU；②平台导出表比接口目录完整（不受分页）。
同一 sku_id 出现两个不同 product_id ⇒ 一定是数据脏了（导出叠错/手工改），要报出来。
现状：七店 3,247 条映射，冲突 0。
