### affiliate code=10000 的真因（抓包对比 URL）
页面发的 URL 带 `X-Bogus` / `X-Gnarly` / `msToken` / `fp` / `device_id` / `aid` / `app_name`
等参数。前三个是**TikTok 动态签名**，由页面 webmssdk 在请求前算。
扩展在 ISOLATED world 里 fetch，SDK 看不见 → 不补签 → 只回 `{"code":10000}`（无 msg）。
修法：`runInPage` 的 `chrome.scripting.executeScript` 加 `world: "MAIN"`，
等同页面自己发的请求，SDK 才会加签。同时也解释了 SKU 接口为什么回 `validating`。
