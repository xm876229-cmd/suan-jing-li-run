## v0.24.1 第三段（计划任务 / 一步启动 / 界面重做）

### 计划任务（src/auto_run.py 重写）
- 一条计划 = 触发(每天/每周几/每月几号 + 时间) + 区间(周期 × 偏移 × 截到哪天)
- 周期：day / week / month / last7 / all；偏移 0=本期 1=上一期 N=N期前；
  截：end 整期 / today 到今天 / day 第 N 天
- `build_range(rule, when)` 返回全套字段（startDate/to/endDateExclusive/startMs/endMs/tzOffset）
- `last_due` / `next_due` / `fires_on`；`quick_rule(kind)` 把「上月/近7天」这类快捷区间转成规则
- 状态文件 `数据/schedule_state.json`：`mark` = 处理水位（判漏跑），`last` = 真跑过的时刻（界面显示）
- 桥 `_schedule_runner` 每 20 秒巡检，容差 600 秒；超时记 missed，界面可一键补跑（按当时该跑的时刻算区间）
