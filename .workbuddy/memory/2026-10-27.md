## 致命 bug：两个函数只有引用没有定义（commit 待记录）

### 现象链
从 v0.3.6 起，所有取数任务点了都没反应：面板只有一行日志、按钮卡灰、
task.log 与桥内存日志都无任务记录。排查了 5 轮（回执时机→后台回收→
上下文失效→消息通道）全部猜错。

### 真因（靠全局 unhandledrejection 上报才抓到）
```
[崩溃] 未处理的 Promise 拒绝：ReferenceError: appendTaskLog is not defined
```
1. `appendTaskLog` / `bridgeLog` / `LOG_KEY` **只有引用没有定义**
   —— v0.3.6 加日志落盘时 Python 字符串替换没匹配上，整段没插入，
   但后续所有代码都在调它。任务第一句写日志就抛，抛在异步链最外层，
   表现得完全静默。
2. `runTask` 调度器在重构 executeTask 时被误删，但 `runTaskThenCalc`
   和 `executeTask` 仍在调用它 → 第二次 ReferenceError。

### 教训（重要）
- 用字符串替换改代码后**必须静态校验符号完整性**，不能只看 node --check
  （语法通过 ≠ 引用存在）
- 后台脚本必须挂 `self.addEventListener("unhandledrejection")` 并把堆栈
  送到外部日志，否则 MV3 的静默失败几乎无法远程定位
- 静态检查脚本：提取所有 `name(` 调用，减去 function/const/let 定义与内置 API

- 补回 bridgeLog / appendTaskLog / LOG_KEY
- 补回 runTask 调度器（TASK_IMPL 分派 + all 分支 + 自愈重试）
