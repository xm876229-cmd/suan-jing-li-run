# 成本表放这里

## 怎么用（两步，只维护一次）

1. 把成本表（xlsx / xls / csv，两列：商品编码 + 成本）丢进这个文件夹
2. 执行一次导入：

```bash
python -m scripts.import_costs "data/costs/你的成本表.xlsx"
```

导入后生成两张文件：

| 文件 | 作用 |
| --- | --- |
| `master.csv` | 主成本表，程序算账时只认这张 |
| `history.jsonl` | 变更流水，每一条涨价/降价/新增都留痕 |

## 为什么不是"直接读最新那份表"

因为那样有三个坑：

1. **覆盖即丢失**：新表没带某个老编码，那个商品下次算账成本就变 0，净利虚高
2. **无法追账**：上个月成本多少、哪个月涨的，覆盖式没有任何记录
3. **表格易读空**：成本表常有合并单元格、多级表头，覆盖式一出错就是整表读空

增量合并的规则：

- 新编码 → 追加
- 老编码价格变了 → 更新，并记一条流水（旧价 → 新价、时间）
- 价格没变 → 不动

## 新增商品时要做什么

只有一件事：**再导一次成本表、再执行一次上面的导入命令**。

不需要的编码不用删，主表会一直留着。第一次没有主表时，程序会自动把目录里最新的表导入并建表，连命令都不用执行。

## 成本数据的去向

这一目录下的表格与主表**不进版本库**（已 gitignore），不会上传到 GitHub。
