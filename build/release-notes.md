净利助手 v0.24.12

这一版是全面体检：修掉两处「点了没反应」的界面故障、三处会丢数据的隐患，
并把「打包前自动检查」补上，免得再发出带病的版本。

一、「导入数据」整页回来了（v0.24.10 的误删）

上一版删「重新计算」页时，把紧挨着的「导入数据」整页一起删掉了：
导航还在、脚本还在，点进去却是空白，传表也没地方传。
现在页面、店铺/国家下拉、拖放区、已传文件列表全部恢复。

二、报表「查看」修好了

报表列表传给后端的是「自动/店名/文件.xlsx」，后端只按纯文件名找，
于是永远提示「找不到这个报表」。现在按相对路径找（老的 name 参数也兼容），
点「查看」就能看到汇总和费用拆解，不用打开 Excel。

三、重算不会再把旧报表弄丢（最重要的一条）

以前的顺序是「先把同名旧报表挪进回收站，再开始算」。
一旦这次算失败——表头不对、文件被 Excel 占着、数据不完整——报表页上
就凭空少一份，而数字还是旧的那版也没了。
现在改成：先算到临时文件，**算成功了才换名**；失败时旧报表原样保留，
临时文件自动清掉。自动核算（驾驶舱运行 / 卡片重算）和手动核算都改了。

四、手动核算加锁

连点两次「计算」、或开着两个窗口同时点，两个核算子进程会往同一个文件名里写。
现在同一家店同时只算一个，第二次直接提示「这家店正在计算中」。

五、下载与报表列表

· 下载目录里同名报表直接覆盖，不再堆 (2)(3)(4)；文件被 Excel 打开时退回另存
· 「另存」按房间取默认目录：手动房间不会因为输入框被清空而存进自动的目录
· 一批里某一份失败（被占用、同名）不再整批报错，其余照存
· 报表列表过滤 _已删除 / _隔离_日期 / ~$ 锁文件 / 算到一半的临时文件
· 订单晚到时的自动补算，报表落在 报表\自动\<店名>\（以前写回老布局）
· 老的「临时手动 / 手动核算」目录，启动时归到 报表\手动\ 下

六、看不见但该修的

· 跨域收窄：桥以前对任何网站都回 Access-Control-Allow-Origin: *，
  等于随便一个网页都能让本机跑核算、往数据目录传文件。
  现在只允许扩展（chrome-extension://）和本机页面
· 上传落盘统一走原子写，断电不会留下半截表格
· 并发上传不再丢文件类型（记录文件写入加锁）
· 打包前自动做脚本符号检查：界面/扩展里「只有调用、没有定义」的函数
  node --check 查不出来（上一版的 fileToB64 就栽在这）。
  检查器现在覆盖 bridge/ui.py 内嵌脚本，并核对导航里的页面在 HTML 里是否存在
