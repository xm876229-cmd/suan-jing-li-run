净利助手 v0.24.5

这一版把数据文件夹彻底改成中文，并修掉了三个「只有用到才会发现」的打包坑。

一、数据文件夹现在真的全是中文了
上一版把子目录改成了中文，但改名只发生在「程序启动的那一刻」，而且只对
当时那个数据目录生效。于是出现了一个很迷惑的场面：程序里已经是 数据\店铺，
可打开程序文件夹一看，里面还是 stores / capture / costs。

现在改名做成了一个独立步骤，打包、同步、启动三处都会调，谁也不用等谁。
这台机器上实测：免安装版 8 处、安装版 6 处、项目目录 2 处，全部改成中文，
45 个店铺文件一个没动。

数据\ 下面现在是：
  店铺\        每家店一个文件夹：收件箱（原始表）/ 商品SKU表 / 快照
  成本\        成本主表 master.csv
  链接映射\    SKU 与商品链接的对应关系
  抓包记录\    扩展抓到的接口原文，纯排查用，可以定期清
  导出\        取数过程中的中转（收件箱）
  日志\        运行日志
  回收站\      在「导入数据」页删掉的文件会挪到这里，能找回来

二、修掉三个打包坑

1. 免安装包把「数据目录.txt」打进去了
   那里面写的是相对路径 ..\..，用户解压到桌面，数据根就会解析成「桌面的上一级」——
   数据、配置、报表全散落在程序文件夹外面，卸载清不掉、备份也找不到。
   现在这个文件不进包；便携版本来就该自包含。

2. 打包排除规则只认英文目录名
   目录一改中文，「数据/stores」「数据/capture」这些规则全部失效，
   结果 45 个店铺文件（订单 + 快照）会被塞进安装包和 zip：体积几百 MB，
   还是别人不该看到的经营数据。现在中英两套名字都认，并且发布校验会直接拦下来
   （zip 里出现店铺数据或 数据目录.txt 就拒绝发布）。

3. 全新安装时成本表没拷过去
   安装程序拷种子数据用的是英文路径 数据/costs/master.csv，目录改中文后静默失败——
   装完成本表是空的，第一次核算所有成本按 0 算，净利虚高，界面上完全看不出原因。
   现在拷到 数据/成本/master.csv，建目录也都用中文名。

三、验证过的事

把新包解压到一个空目录，直接启动：
  · 数据根就是解压目录本身，上级目录一个文件都没多出来
  · 数据\ 下自动建好 抓包记录 / 导出 / 收件箱 / 店铺 / 成本 / 日志 / 链接映射
  · 成本表种子 240 KB 正常落地（不是空的）
  · 配置 8 个 json 全部补齐，自检报告「一切正常」

四、其他
  · 同步「默认配置」时不再带 .bak：程序读坏配置会回退到 .bak，
    而默认配置里的 .bak 是打包那天的旧值，恢复出来反而更错
  · 《使用说明.txt》补上 数据\ 下面每个子目录是干什么的，以及怎么备份 / 换电脑

更新方式
- 免安装版：解压覆盖（数据/配置/报表 都在程序目录里，先备份再覆盖）
- 安装版：直接跑新的安装包，会覆盖程序、保留 数据/配置/报表
- 更新后重启程序，并在浏览器扩展页点一次「刷新」

注意：如果你之前解压过旧版，程序目录里可能还留着 数据目录.txt。
它会让数据存到别的地方去。不确定的话，删掉它，数据就会回到程序目录。
（程序「调试」页会显示当前实际使用的数据路径。）
