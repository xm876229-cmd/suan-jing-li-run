净利助手 v0.24.4

这一版主要按「好用」把几个页面重排了一遍，另外汇总页可以不要合计行了。

一、区间日历：一次点完起止日期
- 点一下日期按钮就弹出日历（不用再去点那个小图标）
- 第一次点是起点，第二次点是终点，点完自动关
- 先点终点也没关系：第二下比第一下早，程序自动把早的当起点
- 带「上月 / 本月至今 / 近 7 天 / 近 30 天」四个快捷
- 驾驶舱总控、每张店铺卡、开始核算页都用同一套

二、修掉「日历点开几秒自己收回去」
根因不是日历：驾驶舱每 3 秒会重绘整面卡片墙，正在打开的原生日历浮层被一起销毁了。
现在日历挂到页面外层，重绘不影响它；卡片上的区间也改成存在内存里，
重绘不会把你刚选的日期清掉。

三、导入记录可以删了
「已经传了哪些」加了勾选、全选、批量删除和单行删除，右上角显示总占用。
删除只是挪进 数据\回收站\时间\（连店名、分类目录都保留），随时能挪回来。
顺带修了列表里一排「undefined 1 · undefined 1」的标签。

四、「开始核算」页重排
分成 ① 用哪批数据 ② 算哪家店、哪段时间 ③ 出报表，三段各管一件事；
页面开头一句话说清：这页是「用手上已有的数据出报表，不重新去店铺取数」。

五、「报表」页重排
筛选、批量操作、下载位置分成三行；全选 / 已选份数 / 删除按钮联动；
表格行距收紧，一屏能多看几份。

六、设置里的两个目录可以点选了
输入框旁边加了「选择文件夹…」和「打开」，不用再手打路径。

七、数据子目录全部改中文
数据\ 下面现在是：抓包记录 / 导出 / 成本 / 链接映射 / 日志 / 店铺，
每店里面是 收件箱。老版本的英文目录会在启动时自动改名搬过来；
万一有文件正被占用改不了，下次启动再试，数据一个都不会丢。

八、汇总页可以不要合计行
「计算参数 → 报表列」新增「显示合计行」开关。关掉后导出的汇总页只有每条链接，
没有那一行「合计」；位置（底部 / 顶部首行）照旧可选，关掉时置灰。

更新方式
- 免安装版：解压覆盖（数据/配置/报表 都在程序目录里，先备份再覆盖）
- 安装版：直接跑新的安装包，会覆盖程序、保留 数据/配置/报表
- 更新后重启程序，并在浏览器扩展页点一次「刷新」
