净利助手 v0.24.15

这一版不修 bug，专门做优化。

一、大店取数更快、更省磁盘

· 快照改用硬链接：40MB 订单不再真复制一份，建快照从「几秒 + 40MB」变成瞬间
· 快照行数统计不再逐行解析 CSV，2MB 文件 0.002 秒
· 上传转 base64 改用浏览器原生 FileReader，大文件不再卡界面

二、界面不再每 3 秒重画

驾驶舱数据没变时跳过重绘，保留悬停状态、少耗 CPU；
顺手清掉已移除店铺的幽灵勾选。

三、手动核算更顺手

· 卡片上的报表名可点，直接跳到「报表 → 手动报表」并只看这家店
· 文件弹窗加「打开文件夹」
· 卡片墙不再每家店重复扫店铺目录

四、文档跟上界面

README / 使用说明按当前版本重写：页面清单、报表两个房间、
手动核算与导入数据的区别、数据目录中文名、快照的新行为。
