净利助手 v0.23.12

这个版本给汇总页加了一个「汇总口径」开关，顺手修掉两个一直在悄悄算错的地方。

新增：汇总页一键切「含样品 / 不含样品」
- 位置在汇总页表头那一行的最右边（表格外），黄底格子，点开是个下拉
- 切成「不含样品」整张表立刻按纯正常订单口径重算：GMV、订单数、件数、买家实付、
  成本、毛利、毛利率、客单价、各项费用、费用占比、净利率、净利（本币/人民币）、
  以及最后的合计行，全都跟着变，不用重新跑一遍核算
- 默认值 = 当前配置（「计算参数」页的「去除 0 元样品订单」），所以刚导出来和以前一样
- 只有勾「导出带公式」的报表才有这个开关；普通报表同一位置是灰字提示

修复
- 明细页「计入成本(CNY)」被乘了汇率：列名写 CNY、值却是本地货币，汇总公式再乘一次，
  成本整整多出一个汇率的倍数（马来站 9.55 倍）。上一版只核对了 GMV / 订单数 / 净利，漏了成本列
- 按量计费的费用在「不含样品」口径下算多：订单服务费、交易手续费本来就不含样品单，
  跟着缩放会多算；某条链接全是样品单时还会退回「导出时的死数」
- 安装版（%LOCALAPPDATA%\JingLiHelper）此前只更新了扩展、exe 一直是旧的：
  sync_all 现在会连程序一起同步，按文件内容哈希比对（只比大小漏过事——
  base_library.zip 两次构建大小一模一样，内容却不同）

打包
- 发布包不再携带 __pycache__ / *.pyc

核对方式
- 按 SUMIFS / IF / IFERROR 的语义写了个求值器，把报表里的公式逐格真算，
  再跟「配置=含样品」「配置=不含样品」两次数值版比对。
  马来一号店 / LR Stationery / LR Home.MY / Chroma Home / Your-Self Home 五家店，
  数据行和合计行累计 9,000 多格，全部一致；「含样品」这一侧与改动前逐位相同

更新方式
- 免安装版：解压覆盖（数据/配置/报表 都在程序目录里，先备份再覆盖）
- 安装版：直接跑新的安装包，会覆盖程序、保留数据
- 更新后重启程序，并在浏览器扩展页点一次「刷新」
