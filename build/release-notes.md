## 之前版本已带来（v0.21.2 / v0.21.3）

### 一、报表列可以自己挑、自己改名

「计算参数 → 报表列（汇总页）」新增一张卡片，专门管汇总页长什么样：

- **勾选展示哪些列**：不想要的列（比如不关心某个占比）取消勾选就不显示，
  想只留「款式编码 / 毛利 / 发单费 / 发单费占比 / 广告花费 / 广告费比 / 净利 / 净利率」也行
- **列标题自定义命名**：每列都能改名，比如把「毛利率」改叫「链接毛利率」、
  把「成本」改叫「商品成本」——只改表头，算法完全不动，留空就用默认标题
- **合计行位置可配**：一张开关，合计行放「表格底部」或「表格顶部（首行）」随你选

> 这套配置**每个国家/店铺单独配**：切参数表顶部的国家下拉即可，互不影响。

### 二、金额列自动标货币，一眼分清哪国钱

GMV / 成本 / 毛利 / 各项费用 / 净利 这些金额列，标题会自动带上国家货币代码：

```
毛利额（MYR）   净利（PHP）   广告花费（MYR）
```

（按你要求用货币代码 MYR / PHP，不用符号）

### 三、新增「链接毛利率」

```
链接毛利率 = (链接GMV − 商品成本(换成本地货币)) / 链接GMV
```

分母用的是 **GMV**（折扣前小计 − 卖家折扣），**不是**买家实付金额，
默认就在汇总页展示，也能在「报表列」里勾选/改名。

### 四、修复公式编辑器「⚠ 不认识」

之前在公式里写「平台佣金率 / 发单费单价 / 人民币汇率」会标红「不认识」，
现在带「率」字的费率名、汇率名已经和「变量候选」「实时校验」完全对齐，
写中文公式不再误报；旧的写法（不带「率」字）也兼容，照常能用。

### 五、映射统一到「订单表识别」

公式里直接写订单表列标题就行，映射关系在「订单表识别」里配，**不再有单独的映射块**；
所有从表格取数的都支持多备胎标题——一行一个、按顺序找，第一个找不到就找第二个，
表格标题改了也不会算错。

### 六、程序文件夹新增「启动桥.bat」入口（新手友好）

取数桥是个后台无窗口服务，平时随窗口自动起；但桥一旦需要手动重启，新手在程序文件夹
（净是一堆文件夹和说明文档）里根本找不到它在哪启动。现在：

- 程序文件夹顶层多了一个 **「启动桥.bat」**，双击就确保桥在后台跑起来——
  **已经在跑就不动、不会起两个**，专治「扩展点了没反应 / 桥好像死了」时无从下手
- 「使用说明.txt」新增「取数桥」专节：它是什么、什么时候要重启、怎么重启、怎么确认活着
- 命令行也能 `jingli.exe bridge` 一键拉起（幂等）

### 七、表头识别支持广告表 / 联盟佣金表 / 链接资料表

- 「订单表识别」升级为 **「表头识别」**，tab 切换四张表：订单表 / 广告表 /
  联盟佣金表 / 链接资料表，各配各的
- 每张表都是「一行一个候选标题」，按顺序找；平台改列名就在对应表里加一条
- 广告表取「商品ID / 花费 / 货币」，联盟佣金取「商品ID / 预估佣金 / 退款」，
  链接资料取「款式编码 / 商品ID / SKU ID / 卖家编码 / 商品名称」
- **广告花费自动换算**：广告表「货币」列是 USD/空 → × 美金汇率换成本地货币，
  MYR/RM 直接用；计算参数里那一行已加文字说明，公式直接引用即可

### 八、计算参数不再全挤在一页

- 顶部改成分段标签：**参数表 / 表头识别 / 报表列 / 净利公式**，一屏一类
- 表头识别内部再用子 tab 切四张表
- 保存 / 试算仍在页面底部，切换分段不影响已填内容

### 九、配置/数据固定，不再跟着「从哪启动」变

以前配置（各国家费率、店铺、计算参数）是跟着 exe 所在目录走的——
换个地方启动 program，就读到另一份配置，甚至读到空配置（费率显示 0 个国家）。
现在改成**数据根与程序目录解耦**：

- 优先看环境变量 `JINGLI_HOME`；其次从程序目录**向上找「数据目录.txt」**（第一行写数据根路径）
- 配置 / 数据 / 报表都统一挂在同一个数据根，任何位置启动都读同一份
- 浏览器扩展仍跟程序目录（那是只读资源）
- 界面「调试 / 诊断」里能直接看到当前数据根路径

## 上一版（v0.21.1）也带来这些

### 公式更好写了

默认公式全部改成中文，照着抄就能用：

```
平台佣金     = 本行GMV × 平台佣金率
交易手续费   = 本行买家实付 × 交易手续费率
发单费       = 本行订单数 × 发单费单价 × 人民币汇率
商品成本     = 本行成本单价 × 人民币汇率
```

- **「本行X」** = 按这一项自己勾选的订单类别算的量
- **费率带「率」字，参数不带**：「平台佣金率」是费率，参数表里那行叫「平台佣金」，两个不撞名
- **多个候选一行一个**：公式框可以多行，点「＋ 加一行」就多一行
- **实时提示**：编辑时下面直接写出来这条公式在算什么，有不认识的词会标红点名

实测：全部公式改中文写法后，GMV / 成本 / 各项费用 / 净利与英文写法完全一致。

### 报表新增「款式编码」列

那一列写的是这条链接下所有 SKU 的款式编码，去重后用 `/` 连接。数据两条路都有：

- **自动**：扩展面板点「链接资料（款式编码）」；或跑「取商品 SKU」时顺带存一份
- **人工**：店铺后台「批量编辑」下载链接资料表，到「店铺」页的「链接资料（款式编码）」卡片传上来

### 报表新增费用占比列

- **发单费占比**、**广告费比**（费用 ÷ GMV），放在费用列后面

## 安装

| 附件 | 用在哪 |
| --- | --- |
| **JingLiHelper-Setup-v0.21.2.exe** | 推荐。双击安装，自动建桌面快捷方式、开机自启、写入卸载信息 |
| **JingLiHelper-Portable-v0.21.2.zip** | 解压即用，不写注册表、不建快捷方式，适合拷到 U 盘 |

装完第一次还要在战斧浏览器里加载一次扩展：
`chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→
选安装目录里的 **浏览器扩展** 文件夹。

安装目录长这样，一眼就懂：

```
jingli.exe              程序本体，双击这个
使用说明.txt             新手先看这个
浏览器扩展\              战斧里加载这个目录
配置\                   费率 / 店铺 / 计算参数 / 预设（可直接改）
数据\                   成本表 / 映射表 / 抓下来的原始文件 / 快照
报表\                   报表产出（按店铺分文件夹）
```

> 附件名是英文的：GitHub 的上传接口会把中文名里的汉字抹掉，
> 传中文名上去下载下来是坏文件。
