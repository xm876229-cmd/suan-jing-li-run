## 这个版本新加了什么（v0.21.1）

### 一、公式更好写了

默认公式全部改成中文，照着抄就能用：

```
平台佣金     = 本行GMV × 平台佣金率
交易手续费   = 本行买家实付 × 交易手续费率
发单费       = 本行订单数 × 发单费单价 × 人民币汇率
商品成本     = 本行成本单价 × 人民币汇率
```

- **「本行X」** = 按**这一项自己勾选的订单类别**算的量。
  「发单费」只勾正常单，它的「本行订单数」就只含正常单
- **费率带「率」字，参数不带**：费率叫「平台佣金率」，
  参数表里那一行叫「平台佣金」——两个不撞名，看到名字就知道指哪个
- **多个候选一行一个**：公式框可以多行，点「**＋ 加一行**」就多一行，
  不用记分隔符（逗号、分号、竖线、换行都认，老配置照常能用）
- **实时提示**：编辑时下面直接写出来这条公式在算什么，
  有不认识的词会标红点名——不用等保存后才发现算错了
- 「净利怎么算」那几行也支持中文，结果名也能引用（`净利 / GMV`）

实测：全部公式改中文写法后，GMV / 成本 / 各项费用 / 净利与英文写法**完全一致**。

### 二、报表新增「款式编码」列

那一列写的是**这条链接下所有 SKU 的款式编码**，去重后用 `/` 连接
（跟模板《V1-净利》的数组公式算出来一样，逐条 51 条链接完全一致）：

```
V1/V2/V61/V9/V46
V68/V67/V69/V70
```

数据两条路都有：

- **自动**：扩展面板点「链接资料（款式编码）」；或跑「取商品 SKU」时顺带存一份
- **人工**：店铺后台「批量编辑」下载链接资料表，
  到「店铺」页的「链接资料（款式编码）」卡片传上来

店铺后台下载的表**没有款式编码那一列**（那是卖家自己加的），
程序会从商家 SKU 推导：`V27-White-10Pcs` → `V27`、
`MY-J68-22cm+clip` → `MY-J68`、`V1【Set-LOVE】` → `V1`。

### 三、报表新增费用占比列

- **发单费占比**、**广告费比**（费用 ÷ GMV）
- 放在费用列后面，一眼看出哪项费用吃掉了多少 GMV

## 上一版（v0.21.0）也带来这些

### 公式不用记英文了

公式里现在**可以直接写中文**：

| 想写什么 | 中文写法 | 英文写法（等价） |
| --- | --- | --- |
| 分摊到这条链接的订单数 | `订单数` | `orders` |
| 件数 | `件数` | `qty` |
| 买家实付 | `买家实付` | `paid` |
| 商品成本单价 | `成本单价` | `cost_cny` |
| 平台佣金率 | `平台佣金` | `params.platform_commission` |
| 交易手续费率 | `交易手续费` | `params.tx_fee` |
| 人民币汇率 | `人民币汇率` | `params.cny_to_local` |

- 费率项的**中文名可以自己起**：「费率」页新增「费率项的中文名」表，改完公式里直接写中文
- 参数之间也能用中文名互相引用：直接写表格里那一行的名字（`商品成本`、`订单服务费`）

### 自动运行开关

「设置」页新增自动运行区：开关、频率（每天/每周某天）、几点跑、算哪个区间、
对哪些店跑、报表下载目录、报表带不带公式，外加「现在跑一次」。
由本地桥派任务（桥是常驻后台进程，浏览器关着也在）。

### 报表按店铺筛选 + 勾选批量下载

报表页顶部按店铺分组，点某家店只看这家的；
每行复选框 + 全选 / 取消全选 / 下载勾选的 / 下载这个店铺的全部；
批量打成一个 zip，zip 内仍按店铺分文件夹。

### 成本表导入

「下载导入模板」生成带示例和说明的 xlsx；
导入是**增量**的：没有的保留、新出现的**新增**、已有的以这次为准（覆盖旧成本）。

### 目录中文名 + 新手引导

用户可见目录一律中文：数据 / 报表 / 配置 / 浏览器扩展。
界面新增「使用帮助」页；根目录放「启动净利助手.bat」和「说明-各文件夹用途.md」。

## 安装

| 附件 | 用在哪 |
| --- | --- |
| **JingLiHelper-Setup-v0.21.1.exe** | 推荐。双击安装，自动建桌面快捷方式、开机自启、写入卸载信息 |
| **JingLiHelper-Portable-v0.21.1.zip** | 解压即用，不写注册表、不建快捷方式，适合拷到 U 盘 |

装完第一次还要在战斧浏览器里加载一次扩展：
`chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→
选安装目录里的 **浏览器扩展** 文件夹。

安装目录长这样，一眼就懂：

```
jingli.exe              程序本体，双击这个
使用说明.txt             新手先看这个
浏览器扩展\              战斧里加载这个目录
配置\                   费率 / 店铺 / 计算参数 / 预设（可直接改）
数据\                   成本表 / 映射表 / 抓下来的原始文件 / 快照
报表\                   报表产出（按店铺分文件夹）
```

> 附件名是英文的：GitHub 的上传接口会把中文名里的汉字抹掉，
> 传中文名上去下载下来是坏文件。

## 需要知道的

- 费率页里各国家的**发单费**按人民币定价，核算时 × 汇率换成本地货币；
  **订单服务费**直接填本地货币（马来西亚 0.54、菲律宾 5），不乘汇率
- 其余 10 个国家的费率和订单服务费还是占位值，用到之前记得填
- 广告 / 联盟 / 链接资料三类数据还需要在真实店铺上跑一遍确认
