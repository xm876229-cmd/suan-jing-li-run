净利助手 v0.24.13

接着上一版继续查，又抓到几处「特定操作才炸」的问题。

一、手动报表「导出带公式」一点就 500

代码里写成了 from src import manual_api，而这个模块在 bridge 下。
平时不影响使用，只有点「手动报表 → 导出带公式」才炸。
已改正并实测导出成功；手动核算的「全部」报表（文件名里没有区间）
现在也能导出带公式版。

二、手动记录丢了就点不了「计算」

按钮原来先看记录里的「有没有订单表」。记录被删/损坏时，文件其实都在，
但按钮直接拦下。现在只看有没有文件，类型交给服务端按真实表头再判。

三、换名失败会把旧报表弄丢

旧报表进了回收站、新文件却换不过去时，现在会把旧的原样放回去；
临时文件名也改短，避免撞 Windows 260 字符路径上限。

四、其他

· 启动自检清理算到一半的临时报表残骸
· 手动核算异常返回人话，不再 500
· 报表按纯文件名查找兼容新布局，老链接照样能打开
· 打包前检查新增「模块导入是否存在」，专治函数体内导入写错模块名
