# 导出文件放这里

## 自动模式（抓包扩展跑通后）

扩展会自动把文件归到这里，你什么都不用管。

## 手动兜底模式（扩展还没装好时也能用）

从店铺后台手工导出后，按这个结构放：

```
data/exports/<店铺id>/<起_止>/
├── 订单_20261001-20261031.xlsx
├── 商品_20261027.xlsx        ← 链接资料 / 商品导出
├── 广告_20261001-20261031.xlsx
└── 联盟佣金_20261001-20261031.xlsx
```

规则只有一条：**文件名里带上关键字**，程序靠关键字识别是哪一类数据。

| 认的关键字 | 对应数据 |
| --- | --- |
| `订单` 或 `order` | 订单明细 |
| `商品` / `链接` / `product` / `sku` | 商品与 SKU 主数据（即「链接资料」） |
| `广告` / `ad` / `ads` | 广告花费报表 |
| `联盟` / `佣金` / `affiliate` / `commission` | 达人佣金报表 |

成本表单独放，用 `--costs` 指过去：

```bash
python -m src.cli --dir "data/exports/demo-my/20261001-20261031" --costs "成本.xlsx" --country 马来西亚
```

> 这个目录下的文件默认不入库（`.gitignore` 已排除），店铺数据不会推到 GitHub。
