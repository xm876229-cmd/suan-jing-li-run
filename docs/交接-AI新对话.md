## 2. 项目在做什么

TikTok Shop 跨境电商（马来西亚 4 店 + 菲律宾 4 店）的**净利核算工具**。
原来靠「人工导表 → 手工填 → Excel 拉公式」，现在是一条流水线：

```
浏览器扩展自动取数 → 本地桥落盘 → Python 核算 → 六页 Excel 报表
```

老大的核心诉求只有一句：**「数字要对，每一项费率都要真的参与计算。」**
他不是要一个"能跑"的程序，是要一个"敢拿去对账"的程序。

### 4.1 0.24.155 是这轮最重要的一版

**根因链**（值得记住，以后遇到类似的"填了不生效"要想到这个模式）：

```
模板 V1-净利 的公式末尾硬编码 *0
  → 程序为了"跟模板一模一样"，做成 switches.super_coupon_enabled=false（出厂 false）
  → 这个开关界面上没有任何入口（三个 switches 在 ui.py 里出现 0 次）
  → calc.py 里还有一行 it["enabled"] = bool(switches.super_coupon_enabled)
     把用户在「计算项」里勾着的「启用」覆盖成关闭
  → 界面上显示勾着、费率填着，实际一分不扣
  → 界面那句"费率填了但没生效"的提醒里，__sc_on 变量从未被赋值，永远不会触发
```

**实测影响**（马来四家，超级优惠券 = GMV × 1.08%）：

| 店 | 区间 | 以前（没扣） | 现在（已扣） |
|---|---|---|---|
| MYT-J1 | 11-01~15 | 83,508.17 | **75,578.14** |
| MYT-J3 | 11-01~15 | 17,542.99 | **15,601.50** |
| MYT-V1 | 11-01~15 | 544.17 | **300.20** |
| MYT-W1 | 11-01~15 | 20,508.06 | **18,531.53** |

这两条是既定口径，不是错账。

## 9. 常用核对脚本模板（写临时脚本时照抄）

```python
# 读报表的「本地币净利」和「CNY 净利」——注意有两列！
import openpyxl
wb = openpyxl.load_workbook(path, data_only=True)
ws = wb['汇总']
total = next(ws.iter_rows(min_row=1, max_row=1, values_only=True))
hdr = [str(c or '') for c in next(ws.iter_rows(min_row=2, max_row=2, values_only=True))]
local = cny = gmv = 0
for i, h in enumerate(hdr):
    if h.startswith('GMV'): gmv = float(total[i] or 0)
    elif h.startswith('净利（') and 'CNY' not in h: local = float(total[i] or 0)
    elif h.startswith('净利（CNY'): cny = float(total[i] or 0)

# 读四类表：一律按 mtime 取最新，不要按文件名优先
from pathlib import Path
f = max((Path(d) / '广告表').glob('*.xlsx'), key=lambda x: x.stat().st_mtime)
```

**两个反复踩的坑**：
- 不要用 `startswith('净利（')` 单条件（会拿到 CNY 那列）
- 不要"优先选不带序号的文件"（每轮新增 `(N)`，不带序号的是旧的）
