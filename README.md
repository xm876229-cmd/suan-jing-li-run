# 算净利润（suan-jing-li-run）

TikTok Shop 跨境电商（马来西亚 / 菲律宾 / 泰国）**单 SKU / 单款式维度净利润核算**项目。

核心工作簿：`V1-净利  -15.xlsx`（注意文件名中「净利」与「-15」之间是两个空格，改名会导致公式与外部引用失效，请勿随意重命名）。

---

## 一、核算口径

净利润 = GMV 口径收入 − 各项成本费用，逐层拆解如下：

| 层级 | 项目 | 说明 |
| --- | --- | --- |
| 收入 | GMV / 买家支付总额 | 买家实付金额，含运费与优惠 |
| 销量 | 订单数 / 客单价 | 客单价 = GMV ÷ 订单数 |
| 成本 | 商品成本（本地货币） | 由「成本」表按商品编码匹配 |
| | 毛利 | GMV − 成本 |
| 平台费用 | 发单费 | 按国家配置（人民币 / 本地货币双口径） |
| | 平台佣金 | 按国家费率 |
| | 交易手续费 | 按国家费率 |
| | 奖金返现服务费 | 按国家费率 |
| | 超级优惠券服务费 | 按国家费率 |
| | 商家成长服务费 | 按国家费率 |
| | 物流服务费 | 按国家费率 |
| 营销 | 达人佣金（联盟佣金） | 来自「联盟佣金」表 |
| | 广告花费 | 来自「广告」表，含广告费比 |
| **结果** | 净利率 / 净利（本地货币） / 净利（人民币） | 人民币口径按「汇率-参数」表换算 |

> 汇率与各费率均为**按国家参数化**，调整口径只需修改「汇率-参数」表，不要在各处硬编码。

## 二、工作表说明

| 工作表 | 行数级 | 作用 |
| --- | --- | --- |
| `汇率-参数` | 3 个国家 | 汇率、发单费、平台佣金率、交易手续费率、各项服务费率 |
| `成本` | ~4.3k | 商品编码 → 成本单价（人民币） |
| `链接资料` | ~1.4k | 商品 / SKU 主数据（product_id、sku_id、Retail Price、Seller SKU） |
| `订单` | ~1.9k | 平台订单明细导出（订单状态、SKU、数量、买家付款总额） |
| `联盟佣金` | ~40 | 达人带货 GMV、预估佣金、退款 GMV |
| `广告` | ~8.2k | 广告计划 / 视频投放花费、SKU 订单数、平均下单成本 |
| `Sheet1` | ~265 | SKU 维度 GMV / 订单数 / 成交件数 中间汇总 |
| `净利润` | 54 | **最终结果表**：按款式编码汇总全部费用项与净利 |

`链接资料`、`订单` 首行标注「这列常态保留 勿删和覆盖」的列，为人工维护列（成本、分配到的订单数、买家付款总额），更新数据时不得整体覆盖。

## 五、协作约定

1. 改动工作簿前先 `git commit`，保证可回滚到上一个口径。
2. 费率、汇率等参数变更必须单独提交，commit 中写明「哪国、哪项、从多少到多少」。
3. `output/` 下产物不提交，脚本必须保证从原始数据可复现结果。
